# ArchiCraft Sample Files (.ifcx)

Welcome to the official sample files repository for **ArchiCraft**.

This repository contains example IFCX drawing files created with ArchiCraft. These files serve as inspiration, reference models for testing, and starter templates for your own architectural and drafting projects.

---

## Included Samples

| Preview | File Name | Description | Category |
| :--- | :--- | :--- | :--- |
| `ArchiCraft-Sample_Farnsworth-House.ifcx` | Complete 3D model of Ludwig Mies van der Rohe's iconic modern masterpiece (1951) | Architecture |
| `ArchiCraft-Sample_Stahl-House.ifcx` | Model of Case Study House #22 by Pierre Koenig (1960) | Architecture |
